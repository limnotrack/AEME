# Set the observations slot of an Aeme object

Set the observations slot of an Aeme object

## Usage

``` r
observations(aeme) <- value

# S4 method for class 'Aeme'
observations(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New observations list to assign.

## Value

A modified Aeme object with updated observations slot.
