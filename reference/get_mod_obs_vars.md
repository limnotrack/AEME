# Get modeled observation variables

Get modeled observation variables

## Usage

``` r
get_mod_obs_vars(aeme, model)
```

## Arguments

- aeme:

  aeme; object.

- model:

  vector; of models to be used. Can be \`dy_cd\`, \`glm_aed\`,
  \`gotm_wet\`.

## Value

Data frame with modeled observation variables and summary statistics.
