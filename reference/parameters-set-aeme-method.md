# Set parameters in Aeme object

Update the parameters slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
parameters(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New parameters data to be assigned.

## Value

A modified Aeme object with updated parameters slot.

## Details

This method updates the "parameters" slot of An Aeme object with new
data.
