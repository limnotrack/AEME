# Calculate TLI 4

Calculate TLI 4

## Usage

``` r
calc_tli4(chla, tn, tp, secchi)
```

## Arguments

- chla:

  Chlorophyll-a concentration in µg/L

- tn:

  Total nitrogen concentration in mg/L

- tp:

  Total phosphorus concentration in mg/L

- secchi:

  Secchi depth in meters

## Value

TLI 4
