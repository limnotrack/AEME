# Add model parameters to Aeme object

Add model parameters to Aeme object

## Usage

``` r
add_param(aeme, param)
```

## Arguments

- aeme:

  Aeme object.

- param:

  data frame with columns "model", "file", "name", "value", "min",
  "max", "module" and "group.

## Value

Aeme object with parameters added
