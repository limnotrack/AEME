# Plot model residuals

Plot model residuals

## Usage

``` r
plot_resid(aeme, model, var_sim = "HYD_temp")
```

## Arguments

- aeme:

  aeme; object.

- model:

  character vector; model(s) to plot. If missing, all models in the Aeme
  object will be plotted.

- var_sim:

  string; of variable to plot

## Value

list of ggplot2 objects
