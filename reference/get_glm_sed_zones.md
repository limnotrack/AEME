# Get number of sediment zones in GLM-AED model

Get number of sediment zones in GLM-AED model

## Usage

``` r
get_glm_sed_zones(aeme, path, lake_dir = NULL)
```

## Arguments

- aeme:

  aeme; object.

- path:

  filepath; where input files are located relative to the current
  working directory.

## Value

Number of sediment zones
