# Set the lake slot of an Aeme object

Set the lake slot of an Aeme object

## Usage

``` r
lake(aeme) <- value

# S4 method for class 'Aeme'
lake(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New lake list to assign.

## Value

A modified Aeme object with updated lake slot.
