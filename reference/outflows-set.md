# Set the outflows slot of an Aeme object

Set the outflows slot of an Aeme object

## Usage

``` r
outflows(aeme) <- value

# S4 method for class 'Aeme'
outflows(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New outflows list to assign.

## Value

A modified Aeme object with updated outflows slot.
