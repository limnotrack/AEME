# Plot a Kw regime suggestion

Plot a Kw regime suggestion

## Usage

``` r
# S3 method for class 'kw_regime'
plot(x, ...)
```

## Arguments

- x:

  an object of class `kw_regime` (see
  [`suggest_kw_regime()`](https://limnotrack.com/reference/suggest_kw_regime.md)).

- ...:

  unused.

## Value

A `patchwork` object combining the observed Kw time series and the
monthly climatology.
