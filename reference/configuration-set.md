# Set the configuration slot of an Aeme object

Set the configuration slot of an Aeme object

## Usage

``` r
configuration(aeme) <- value

# S4 method for class 'Aeme'
configuration(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New configuration list to assign.

## Value

A modified Aeme object with updated configuration slot.
