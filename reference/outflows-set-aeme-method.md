# Set outflows in Aeme object

Update the outflows slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
outflows(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New outflows data to be assigned.

## Value

A modified Aeme object with updated outflows slot.

## Details

This method updates the "outflows" slot of An Aeme object with new data.
