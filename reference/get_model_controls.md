# Get model controls

Get model controls

## Usage

``` r
get_model_controls(aeme = NULL, use_bgc = FALSE)
```

## Arguments

- aeme:

  aeme; object.

- use_bgc:

  logical; switch to use the biogeochemical model.

## Value

A data frame of model controls

## Examples

``` r
if (FALSE) { # \dontrun{
model_controls <- get_model_controls()
} # }
```
