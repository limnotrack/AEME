# Visualise calibrated weir parameters (C, h_inv) from calc_water_balance().

Visualise calibrated weir parameters (C, h_inv) from
calc_water_balance().

## Usage

``` r
plot_weir_calibration(aeme, model)
```

## Arguments

- aeme:

  aeme; object.

- model:

  vector; of models to be used. Can be \`dy_cd\`, \`glm_aed\`,
  \`gotm_wet\`.

## Value

A patchwork object.
