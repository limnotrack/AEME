# Set the water_balance slot of an Aeme object

Set the water_balance slot of an Aeme object

## Usage

``` r
water_balance(aeme) <- value

# S4 method for class 'Aeme'
water_balance(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New water_balance list to assign.

## Value

A modified Aeme object with updated water_balance slot.
