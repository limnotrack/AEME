# Add model output to Aeme object

Add model output to Aeme object

## Usage

``` r
add_output(aeme, out)
```

## Arguments

- aeme:

  Aeme object

- out:

  list with model output loaded with
  [`load_output()`](https://limnotrack.com/reference/load_output.md)

## Value

Aeme object with model output added
