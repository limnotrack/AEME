# Add model output to Aeme object

Stores `out` as the next ensemble member of the `output` slot.

## Usage

``` r
add_output(aeme, out)
```

## Arguments

- aeme:

  Aeme object

- out:

  list with model output loaded with
  [`load_output()`](https://limnotrack.com/AEME/reference/load_output.md)

## Value

Aeme object with model output added
