# Get AED sed_const2d parameters

Get AED sed_const2d parameters

## Usage

``` r
get_aed_sed_const2d_param(aeme, path, lake_dir = NULL)
```

## Arguments

- aeme:

  aeme; object.

- path:

  filepath; where input files are located relative to the current
  working directory.

## Value

Data frame with AED sed_const2d parameters
