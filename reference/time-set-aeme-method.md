# Set time in Aeme object

Update the time slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
time(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New time data to be assigned.

## Value

A modified Aeme object with updated time slot.

## Details

This method updates the "time" slot of An Aeme object with new data.
