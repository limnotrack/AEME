# Set water_balance in Aeme object

Update the water_balance slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
water_balance(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New water_balance data to be assigned.

## Value

A modified Aeme object with updated water_balance slot.

## Details

This method updates the "water_balance" slot of An Aeme object with new
data.
