# Set the time slot of an Aeme object

Set the time slot of an Aeme object

## Usage

``` r
time(aeme) <- value

# S4 method for class 'Aeme'
time(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New time list to assign.

## Value

A modified Aeme object with updated time slot.
