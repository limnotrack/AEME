# Catchment yields

A reference table for catchment nutrient and sediment yields for
calculating inflow nutrients in AEME.

## Usage

``` r
catchment_yields
```

## Format

\## \`catchment_yields\` A data frame with 4 rows and 4 columns:

- Type:

  Type of catchment

- TN_kg/ha/y:

  Total nitrogen yield per hectare per year.

- TP_kg/ha/y:

  Total phosphorus yield per hectare per year.

- TSS_kg/ha/y:

  Total suspended sediment yield per hectare per year.
