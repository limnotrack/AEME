# Set observations in Aeme object

Update the observations slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
observations(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New observations data to be assigned.

## Value

A modified Aeme object with updated observations slot.

## Details

This method updates the "observations" slot of An Aeme object with new
data.
