# Example dataframe of parameters for phytoplankton in the GLM-AED model.

This dataset contains all parameters related to phytoplankton in the
aed_phyto_pars.csv file.

## Usage

``` r
aed_phyto_pars
```

## Format

\`aed_phyto_pars\` A data frame with 564 rows and 5 columns:

- parameter_name:

  Name of the parameter in AED

- group:

  Phytoplankton group for the parameter

- value:

  Default value of the parameter

- description:

  Description of the parameter

- var_sim:

  AEME variable names associated with the parameter, multiple variables
  are separated by a '\|' symbol

## Details

This includes three phytoplankton groups (greens, cyanobacteria an
diatoms).
