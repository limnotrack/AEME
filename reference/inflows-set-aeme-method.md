# Set inflows in Aeme object

Update the inflows slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
inflows(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New inflows data to be assigned.

## Value

A modified Aeme object with updated inflows slot.

## Details

This method updates the "inflows" slot of An Aeme object with new data.
