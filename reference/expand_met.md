# Expand a minimal set of meteorology inputs to a complete set of variables suitable for all models

Expand a minimal set of meteorology inputs to a complete set of
variables suitable for all models

## Usage

``` r
expand_met(met, lat, lon, elev, print.plot = FALSE)
```

## Arguments

- met:

  data frame of source meteorology variables

- lat:

  numeric; latitude

- lon:

  numeric; longitude

- elev:

  numeric; elevation

- print.plot:

  logical; print the plot

## Value

dataframe with expanded met variables
