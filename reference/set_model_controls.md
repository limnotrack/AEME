# Set model controls for AEME object

Set model controls for AEME object

## Usage

``` r
set_model_controls(aeme, model_controls)
```

## Arguments

- aeme:

  Aeme object.

- model_controls:

  data.frame; model configuration, typically loaded via
  [`get_model_controls()`](https://limnotrack.com/reference/get_model_controls.md).

## Value

Aeme object with model controls set
