# Get the path to the AEME data

Get the path to the AEME data

## Usage

``` r
get_aeme_path(aeme, require = TRUE)
```

## Arguments

- aeme:

  aeme; object.

- require:

  If TRUE, an error is thrown if the AEME object does not contain a path
  to the data. If FALSE, NULL is returned if the AEME object does not
  contain a path to the data.

## Value

Path to the AEME data
