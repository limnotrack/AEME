# Set the output slot of an Aeme object

Set the output slot of an Aeme object

## Usage

``` r
output(aeme) <- value

# S4 method for class 'Aeme'
output(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New output list to assign.

## Value

A modified Aeme object with updated output slot.
