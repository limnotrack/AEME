# Get inflow data from Aeme object

Get inflow data from Aeme object

## Usage

``` r
get_inflows(aeme, return_df = FALSE)
```

## Arguments

- aeme:

  aeme; object.

- return_df:

  Logical. If TRUE, returns a single data frame with all inflows. If
  FALSE, returns a list of data frames for each inflow. Default is
  FALSE.

## Value

A list of data frames or a single data frame with all inflows combined.
