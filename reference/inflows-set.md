# Set the inflows slot of an Aeme object

Set the inflows slot of an Aeme object

## Usage

``` r
inflows(aeme) <- value

# S4 method for class 'Aeme'
inflows(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New inflows list to assign.

## Value

A modified Aeme object with updated inflows slot.
