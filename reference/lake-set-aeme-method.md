# Set lake in Aeme object

Update the lake slot of an Aeme object

## Usage

``` r
# S4 method for class 'Aeme'
lake(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New lake data to be assigned.

## Value

A modified Aeme object with updated lake slot.

## Details

This method updates the "lake" slot of An Aeme object with new data.
