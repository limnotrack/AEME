# Set the parameters slot of an Aeme object

Set the parameters slot of an Aeme object

## Usage

``` r
parameters(aeme) <- value

# S4 method for class 'Aeme'
parameters(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New parameters data.frame to assign.

## Value

A modified Aeme object with updated parameters slot.
