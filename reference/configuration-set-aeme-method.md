# Set configuration in Aeme object

Update the configuration slot of an aeme object

## Usage

``` r
# S4 method for class 'Aeme'
configuration(aeme) <- value
```

## Arguments

- aeme:

  An Aeme object.

- value:

  New configuration data to be assigned.

## Value

A modified Aeme object with updated configuration slot.

## Details

This method updates the "configuration" slot of An Aeme object with new
data.
